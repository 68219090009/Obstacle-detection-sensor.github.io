โมดูลเซ็นเซอร์ตรวจจับด้วยอินฟราเรดได้รับการออกแบบมาเพื่อระบบตรวจสอบสินค้าค้างบนสายพาน เพื่อตรวจจับวัตถุอย่างแม่นยำ รวดเร็ว และมีความน่าเชื่อถือสูง เหมาะสำหรับงานอุตสาหกรรม ระบบลำเลียงสินค้า และระบบ Automation ในยุคดิจิทัลที่ต้องการประสิทธิภาพสูงสุด

Wiring & Connection

ข้อมูลการต่อวงจรและพินใช้งาน

ข้อมูลจากการออกแบบระบบตรวจสอบสินค้าค้างบนสายพานด้วยอินฟราเรด เพื่อให้สามารถเชื่อมต่อกับ Arduino ได้อย่างถูกต้องและใช้งานได้จริง

I2C Interface

  • A4 / SDAพินอินพุตอนาล็อกช่อง 4 / สายข้อมูล I2C
  • A5 / SCLพินอินพุตอนาล็อกช่อง 5 / สายสัญญาณนาฬิกา I2C

KY-032 Sensor

  • OUTเชื่อมต่อกับ D10
  • SignalDigital Output จากเซ็นเซอร์

LCD 16x2

  • A4เชื่อมต่อกับ I2C SDA
  • A5เชื่อมต่อกับ I2C SCL
  • Address0x27

สรุปการทำงาน

  • Digital Outให้สัญญาณดิจิทัลจากเซ็นเซอร์
  • Arduino UNO R3รับสัญญาณที่ D10 สำหรับประมวลผล
หมายเหตุ: KY-032 Sensor Module (Infrared) จะให้สัญญาณเอาท์พุตแบบดิจิทัลเพื่อใช้เป็นตัวบอกสถานะในระบบตรวจสอบสินค้าค้างบนสายพาน โดยเชื่อมต่อกับ D10 ของ Arduino® UNO R3 เพื่อประมวลผลและแสดงผลบน LCD 16x2
ทำไมต้องเลือกเรา

  • ประหยัดพลังงานและใช้งานง่าย
  • รองรับการใช้งานในระบบอุตสาหกรรมและอุปกรณ์อัตโนมัติ
